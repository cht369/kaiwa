# 开蛙

一个单文件网页小游戏。双击 `index.html` 就能玩，不用装任何东西。

![主界面](screen-1.png)

---

## 怎么玩

一局十轮，每轮发八张蛋。

**双击**拆开一张，露出颜色和点数。
**再双击**是敲——敲能升档，也可能跌，敲满三下会碎。

拆够了点结算，十个轮次打完，这一局结束。

---

## 规则

**点数**：一张卡的底分，1~9 点。

**倍率**：由颜色决定，从奶白的 ×1 到仙剑的 ×275。

**同色**：同一种颜色出现 N 张，这 N 张的倍率各乘 N。
三张抹茶（×2）= ×6。五张触发**满贯 ×3**。

**牌型**：同色三张起，筹码和倍率各加一档。

**敲**：第一锤升 56% 跌 6%，第二锤升 36% 跌 26%，第三锤升 16% 跌 46%。
**越敲越苦，第三锤多半是亏的。**

**极光**：偶尔有卡带彩虹边框（3%），敲一下有 12% 变成极光，8% 会散掉。
极光卡让倍率翻倍，两颗 ×4，三颗 ×8。

**连击**：第 1~3 轮 ×1.1，4~6 轮 ×1.35，7~9 轮 ×1.9，第 10 轮 ×2.6。

## 一些说明

**这是个单文件游戏。** 所有图片都内联成 base64，所以只有一个 `index.html`，4.4 MB。双击即玩，也可以直接拖进浏览器。

**数值是跑过模拟的。** 五个矿的期望产出、连击曲线的强度、极光和满贯的触发率，都用 6000 局模拟验证过。不是为了"看起来平衡"，是为了让"偶尔爆一次"真的会发生。

**设计意图**：这游戏想说的是——**你以为自己在算，其实一直在赌。而赌对一次，抵一百次算。**

敲蛋的规则是公开的，概率写在引导里，一个数都没藏。玩家知道了照样会敲第三下。这是设计的一部分，不是漏洞。
